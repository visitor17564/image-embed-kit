# Image Embed Kit

![Image Embed Kit로 노트에 삽입한 이미지를 편집하는 모습](assets/image-tool-test.gif)

Obsidian 데스크톱 노트에 삽입한 이미지의 표시 크기를 조절하고 캡션을 붙이는 플러그인입니다. 원본 사진은 다시 저장하지 않습니다. [English](./README.md)

## 사용법

1. 읽기 모드나 Live Preview에서 이미지에 마우스를 올리거나 한 번 클릭합니다.
2. 좌우 손잡이를 드래그하면 원본 비율을 유지하며 표시 폭이 바뀝니다. 손잡이에서 방향키로도 폭을 조절할 수 있습니다.
3. 이미지를 더블클릭하거나 확대 버튼을 누르면 파일명과 원본 크기가 표시됩니다. 확대·축소, 100%, 화면 맞춤을 선택하고 Esc나 배경 클릭으로 닫습니다.
4. 캡션 버튼을 누르면 너비와 한 줄 캡션을 편집할 수 있습니다. 너비를 비우면 자동 크기로 돌아갑니다. 캡션은 내용만 숨겨 두거나 입력값을 비워 삭제할 수 있습니다.
5. Live Preview에서는 같은 도구막대의 **이 블럭 수정**을 눌러 이미지 링크 원문을 편집할 수 있습니다. 손잡이를 놓거나 캡션 설정에서 저장하면 노트 파일에도 바로 반영됩니다.
6. 읽기 모드와 Live Preview에서 이미지를 한 번 클릭한 뒤 **Delete**를 누르면 그 위치의 이미지와 플러그인 캡션이 삭제됩니다. 원본 첨부파일과 같은 이미지를 삽입한 다른 위치는 유지됩니다.
7. Live Preview에서 이미지를 클릭한 뒤 **Enter**를 누르면 이미지와 캡션 아래에 새 줄이 생기고 입력 커서가 이동합니다. 이미지가 문장 안에 있으면 그 문장의 줄 아래에서 입력을 이어갑니다.

키보드로는 명령 팔레트의 **Image Embed Kit: 노트 이미지 선택**에서 파일명·줄 번호를 검색합니다. 편집기에 커서가 있다면 **현재 이미지 설정** 명령을 사용할 수 있습니다.

## 저장 방식과 지원 범위

- 크기는 Obsidian [기본 이미지 임베드 문법](https://obsidian.md/help/embeds)에 기록합니다. 예: `![[사진.png|320]]`, `![기존 대체 텍스트|320](사진.png "기존 제목")`. 같은 파일을 여러 번 삽입해도 각 위치를 독립적으로 편집합니다.
- 캡션은 이미지 바로 뒤에 기울임꼴 Markdown과 숨은 식별 주석으로 저장합니다. 독립된 줄의 이미지에는 아래 문단, 본문 속 이미지에는 같은 줄을 사용합니다. 기존 대체 텍스트와 직접 작성한 이웃 문단은 보존합니다.
- 플러그인을 꺼도 기본 너비와 표시용 캡션을 읽을 수 있습니다. 숨긴 캡션은 주석 안에 남습니다. 설정창을 연 뒤 문서가 바뀌면 저장을 멈추므로 이미지를 다시 선택해 주세요.
- 첫 버전은 보관함에 있는 이미지의 위키 임베드와 일반 Markdown 임베드를 지원합니다. 표 셀, 다른 노트를 펼쳐 보이는 영역, 원격 이미지 및 소스 모드의 마우스 동작은 다루지 않습니다.

## 로컬 설치

설치 파일 세 개는 [최신 GitHub 릴리스](https://github.com/visitor17564/image-embed-kit/releases/latest)에서 받습니다.

보관함의 `.obsidian/plugins/image-embed-kit/`에 `manifest.json`, `main.js`, `styles.css`를 복사합니다. **설정 → 커뮤니티 플러그인** 목록을 새로고침하고 **Image Embed Kit**를 켭니다. 사용을 위해 별도 프로그램이나 라이브러리를 설치할 필요가 없습니다.

## 개발

```sh
npm ci
npm test
npm run build
```

빌드 시 esbuild만 사용합니다. 실행 시 Obsidian이 제공하는 API와 CodeMirror를 사용합니다.
